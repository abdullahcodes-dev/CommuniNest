# 🏡 CommuniNest

> Connecting Communities. Inspiring Change.

## 📌 About

CommuniNest is a modern community engagement platform that empowers neighborhoods to report local issues, discover community events, volunteer for local causes, reconnect lost items, and work together to build stronger communities.

This project is being built using only HTML, CSS, and JavaScript as part of the **#BuildWithAffaq** Coding Challenge.

---

## 🚀 Planned Features

- Community Dashboard
- Report Local Issues
- Community Feed
- Lost & Found
- Volunteer Board
- Community Events
- Search & Filters
- Analytics Dashboard
- Dark Mode
- Responsive Design

---

## 🛠 Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)
- LocalStorage
